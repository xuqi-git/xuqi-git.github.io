rclone — Personal Backup Client

This page is the homepage of a personal-use OAuth application named rclone. The application is operated by the site owner for one purpose only: running the open-source tool rclone to back up the owner's own computers to the owner's own Google Drive.

It is not a public service. There is no sign-up, no third-party access, and no data collection of any kind.

See the Privacy Policy for details.
