Privacy Policy

Last updated: 2026-11-13

The OAuth application named rclone is a personal-use client of the open-source tool rclone. It is used solely by its owner to access the owner's own Google Drive in order to back up the owner's own files.

  • Data accessed: files in the owner's own Google Drive, only through rclone running on the owner's own machines.
  • Data collection: none. The application collects no personal data from any user, because the owner is the only user.
  • Data sharing: none. No data is shared with, sold to, or processed by any third party.
  • Data storage: OAuth tokens are stored only in the local rclone configuration files on the owner's own machines.
  • Revocation: access can be revoked at any time from the owner's Google Account permissions page.

Contact: via the owner's GitHub profile (github.com/xuqi-git).
